Who I am

I'm Luai — online I go by Lasovar. I'm a game development programming student, and the part of game development I enjoy most is the part players never see: engine architecture, rendering, tooling, and the editor workflows that make everyone else on a team faster.

Right now I'm working on BANX, an upcoming hand-animated action-adventure on Steam. Alongside it I'm building Quelos, a cross-platform C++ engine and editor, from scratch, and I prototype gameplay in Unity and join game jams.

What I care about

Editors should be fast. A lot of engines treat the editor as “just a tool”, but it's where developers spend most of their day. I don't want to stare at a screen for five minutes waiting for code to compile or assets to reimport.

Tools are for the whole team. A game isn't made only by programmers. Level designers and artists need workflows with as little friction as possible — visual scripting that compiles to native code, version-control-friendly scenes, and file locking right inside the editor.

Open source · MIT In development

Quelos

A cross-platform game engine focused on editor functionality and developer workflow — a fast, snappy editor that doesn't compromise the runtime's performance, or the developer's time. The editor runs on Windows, macOS and Linux.

  • C++
  • Flecs ECS
  • Diligent Engine
  • Vulkan · DX12 · DX11
  • Slang

Current goals
  • Reference-counted asset management
  • Asset cooking workflow
  • Fully abstract renderer backend
  • Per-API shader compilation
